# Fly Brain Behavior Assets v2 — Codex Ready

Species: Drosophila melanogaster.

All behavior animations use the same fly visual model and are provided as
transparent 96x96 PNG frames, small looping GIFs, and 8-frame sprite sheets.

Included:
idle, walk, feed, groom, scare, burn, freeze, shock,
mate (two-fly mating pair), takeoff, land, sleep, happy, hurt, dead, confused.

Effects:
- effects/fire_overlay.png
- effects/ice_overlay.png
- effects/shock_overlay.png

Behavior mapping should be driven by the existing GroupBrain output.
Do not invent telemetry or replace brain logic. The MATE animation is a
scientifically grounded paired-fly depiction without explicit bodily-fluid
detail.

Recommended Discord/dashboard use:
- GIFs for compact previews.
- PNG frames for frame-by-frame dashboard animation.
- Sprite sheets for custom renderers.

All assets are intentionally small and transparent for Discord and lightweight
hosting.
