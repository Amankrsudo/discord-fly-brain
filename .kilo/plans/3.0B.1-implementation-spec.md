# Fly Brain 3.0B.1 Implementation Specification

**Date:** 2026-09-25
**Status:** Pre-implementation specification (Phase 1: Core Escape Pathway)

## 1. Objective

Replace the 3.0A startle scaffold with a biophysically-grounded escape circuit derived from Drosophila connectome data (FlyWire FAFB + MANC) and physiology literature. This phase (3.0B.1) implements only the core visual-to-motor escape pathway that reproduces short-mode "tuck and jump" escape timing.

## 2. Scope Exclusion

### 2.1 In Scope (3.0B.1 Core)
- LC4, LPLC2 visual input -> GF integration (brain level)
- GF -> TTMn (electrical + chemical, jump)
- GF -> PSI (electrical + chemical) -> DLMn (chemical, wing downstroke)
- Escape signal extraction and 2.0 system integration

## 5. Weight Derivation Formula (Calibration Method)

All synaptic weights in the LIF voltage-based model are **calibrated** from DIRECTLY_MEASURED latency targets using the formula:

```
W_calibrated = (V_threshold - V_rest) / exp(-dt / tau_m)
```

This is the **minimum weight** for a postsynaptic neuron to cross threshold from a single presynaptic spike, given:
- `dt` = 1 tick (1 ms, §6.1)
- `tau_m` = postsynaptic neuron's membrane time constant
- Voltage-based integration (not conductance-based)

| Synapse | Postsynaptic tau_m | Gap (mV) | Formula | Result | Rounded |
|---------|-------------------|----------|---------|--------|---------|
| GF->TTMn (elect) | 10.0 | 15.0 | 15.0 / exp(-1/10) | 16.58 | **17.0** |
| GF->PSI (elect) | 15.0 | 15.0 | 15.0 / exp(-1/15) | 16.03 | **16.5** |
| VPN->GF (chem) | 5.0 | 20.0 | 20.0 / exp(-1/5) | 24.43 | **25.0 split** |
| PSI->DLMn (chem) | 10.0 | 15.0 | 15.0 / exp(-1/10) | 16.58 | **17.0** |

**VPN->GF split:** 2,290 LC4 vs 1,443 LPLC2 synapses → ratio 0.612:0.388
- LC4: 24.43 * 0.612 = 14.95 -> **15.0**
- LPLC2: 24.43 * 0.388 = 9.48 -> **10.0**

**135 uS conductance note:** The 135 uS value is from the eNeuro 2019 conductance-based model (INFERRED fit to ~1-2 ms latency). Our LIF model is voltage-based and cannot represent conductance directly. The 17.0 mV weight is calibrated to reproduce the same 1-tick propagation latency (DIRECTLY_MEASURED: von Reyn et al. 2014, King & Wyman 1980). The conductance value is preserved in the JSON as metadata but is NOT used in simulation. This is APPROXIMATION.

## 6. Simulation Mapping

### 6.1 Time Scale

| Biological Unit | Simulation Unit | Conversion | Evidence |
|-----------------|-----------------|------------|----------|
| 1.0 ms real time | 1 tick | dt_ms_per_tick = 1.0 | APPROXIMATION (3.0A convention) |
| Short-mode total latency | 11-15 ticks (spec baseline) | 1 tick = 1ms | DIRECTLY_MEASURED latency (15-35ms in research) minus phototransduction (~10-20ms not modeled) |

> **Justification:** 3.0A `Neuron.dt` defaults to 1.0ms (neuron.py:30). Each biological tick call represents 1 ms of neural dynamics. The 2.0 `FlyController` calls `biological_brain.step()` once per wall-clock tick (fly_controller.py:77). This means the biological escape circuit completes its dynamics within a single 2.0 command burst (COMMAND_TICKS=6). Phototransduction (~10-20 ms) is bypassed per §2.2 — visual current is injected directly into VPNs.

> **Timing note (3.0B.1 implementation):** The 11–15 tick target was calibrated against the spec's looming currents (LC4=3.0, LPLC2=2.0 mV/tick, §7.1). With those currents, VPs reach threshold at tick ~8–9 (due to lower input strength). The implementation calibrates currents to 5.0 mV/tick for both LC4 and LPLC2 (see §7.1 calibration note) so both VPs fire simultaneously at tick ~4, enabling GF summation. This produces escape signal at **tick 6** and flight signal at **tick 8** — faster than the 11–15 tick baseline but still within the biologically-measured short-mode latency range (15–35 ms) when the ~10–20 ms phototransduction delay (bypassed per §2.2, OUT OF SCOPE per §2.2) is included. The neural conduction portion (6–8 ticks) is shorter than the 11–15 tick spec baseline because calibrated input currents are stronger than the spec's approximation values. Synaptic weights and inter-neuron delays are unchanged from the spec.

### 6.3 Weight Calibration (see §5 for formula)

All weights are calibrated to reproduce DIRECTLY_MEASURED propagation latencies:
- GF->TTMn: 1-2 ms latency (von Reyn 2014) -> 17.0 mV -> fires in 1 tick ✓
- GF->PSI: 1-2 ms latency -> 16.5 mV -> fires in 1 tick ✓
- PSI->DLMn: 2-3 ms latency (King & Wyman 1980) -> 17.0 mV -> fires in 1 tick (of the tick where PSI spike arrives) ✓

### 6.4 Engine Execution (unchanged from 3.0A)

```
For each step(sensory_input):
  1. Inject sensory current into input neurons (blocked if refractory)
  2. Process scheduled spike queue (from previous ticks)
  3. Integrate all neurons (exponential decay + 0.0 input_current)
  4. Threshold check -> spike emission
  5. Schedule synaptic propagation to targets (with delay)
  6. Return outputs (TTMn, DLMn membrane potentials)
```
Matches `NeuralEngine.step()` exactly (neural_engine.py:28-68). No engine modifications required.

## 7. 2.0 System Integration

### 7.1 Sensory Input Mapping (Biological-Extended Interface)

The `_map_sensory_input()` method translates 2.0 stimulate dict keys to biological neuron currents. Three tiers of mapping:

**Tier 1: Biological-specific looming keys (optional)**
If present in stimulate dict, these directly drive the visual pathway:
```python
LOOMING_MAP = {
    "loomingLeft":  {"LC4_L": 5.0, "LPLC2_L": 5.0},
    "loomingRight": {"LC4_R": 5.0, "LPLC2_R": 5.0},
    "loomingFront": {"LC4_L": 3.0, "LC4_R": 3.0, "LPLC2_L": 3.0, "LPLC2_R": 3.0},
}
```
> **CALIBRATION NOTE (deviation from spec baseline):** The spec baseline defined LC4=3.0/2.0 mV/tick proportional to synapse counts (2290:1443). However, with identical LC4/LPLC2 biophysics (same tau_m, threshold, V_rest), asymmetric currents drive the two VPs to threshold at different ticks (~8 vs ~16). GF requires both LC4 *and* LPLC2 spikes to arrive within the same ~1-tick window (Ache 2019 summation model; spec §12.2 Risk #2). The synapse-count ratio is already encoded in VP->GF synaptic weights (15.0:10.0 = 1.5:1). Therefore, equal input currents (5.0 mV/tick) are used to ensure simultaneous VP firing. This is explicitly an **APPROXIMATION** — no direct biological measurement exists for the effective current delivered to a collapsed single-neuron representation of a population. The resulting neural conduction latency (tick 6 for escape signal) is shorter than the spec's 11–15 tick baseline but falls within the biologically-measured range (15–35 ms) when the bypassed phototransduction delay (10–20 ms) is included. See §6.1 timing note.

These keys are **optional** — if absent (pure 2.0 mode without looming detection), the circuit receives 0 for these inputs. No 2.0 code changes required.

**Tier 2: Existing 2.0 stimulus keys (fallback)**
Mapped to VPN activation as proxy triggers:
```python
FALLBACK_MAP = {
    "lightLevel":   {"LC4_L": 1.5, "LC4_R": 1.5},
    "nociception":  {"LC4_L": 5.0, "LC4_R": 5.0, "LPLC2_L": 5.0, "LPLC2_R": 5.0},
    "dangerOdor":   {"LC4_L": 2.0, "LC4_R": 2.0},
    "touch":        {"LC4_L": 1.0, "LC4_R": 1.0},
}
```
> **CALIBRATION NOTE (deviation from spec baseline):** The spec defined nociception currents as LC4=4.0, LPLC2=2.0. The implementation uses 5.0 for all four VPs for the same GF summation reason — both LC4 and LPLC2 must fire simultaneously on each hemisphere. This is an **APPROXIMATION** — the nociceptor→VPN connection anatomy is undocumented (spec §12.2 Question #6).

**Input current calibration (APPROXIMATION):**
- `loomingLeft=1.0` -> LC4_L gets 3.0 mV/tick
- This produces LC4 firing in ~8.4 ticks (calibrated to approximate the ~10-20 ms phototransduction+VPN response latency from research report §5)
- The 3.0 mV/tick value is APPROXIMATION — no direct biological measurement exists for the effective current delivered to a collapsed LC4 neuron

## 9. Electrical Synapse Representation

### 9.1 Current Abstraction Limitation

The `Synapse` dataclass (synapse.py:14) has fields: `source`, `target`, `weight`, `sign`, `delay`, `neurotransferase`, `enabled`. There is **no** `synapse_type` field. Electrical and chemical synapses are indistinguishable except by convention (neurotransmitter="ShakB" for electrical).

### 9.2 Mapping Rule (JSON -> Synapse objects)

| JSON "type" | Synapse Fields | Directions |
|-------------|----------------|------------|
| `"chemical"` | One Synapse(source, target, weight, sign, delay, neurotransmitter) | Unidirectional |
| `"electrical"` | Two Synapse entries (both directions) | Bidirectional pair |

For electrical synapses, the loader creates two `Synapse` objects with:
- `sign=Sign.EXCITATORY` (functional depolarization; gap junctions are neither exc nor inh by nature)
- `neurotransmitter="ShakB"` (identifies as electrical/gap junction)
- Symmetric `weight` and `delay` values
- The `"type": "electrical"` marker is consumed at load time, not stored in Synapse

**Note:** This representation loses true gap junction properties (instantaneous current flow, voltage-dependent). Each direction is treated as a delayed spike-mediated voltage injection. This is APPROXIMATION (see §12.2).

### 10.3 Test Spike Injection Mechanism

To inject a deterministic GF spike for latency testing (without waiting for VPN integration), tests use **sensory injection** — the existing `NeuralEngine.step()` accepts any neuron ID in `sensory_input` and injects current directly:

```python
# Method: inject enough current to GF_L in one step to cross threshold
# GF needs: V_rest + W * exp(-1/tau_m) >= V_threshold
# -65 + W * 0.8187 >= -45  =>  W >= 24.4
# Injecting 25.0 mV ensures spike in current tick
brain.step({"GF_L": 25.0})  # GF_L spikes this tick, schedules propagation

# Next tick: TTMn_L and PSI_L receive electrical input
brain.step({})  # TTMn_L, PSI_L should spike
# Tick after: DLMn_R receives PSI input  
brain.step({})  # DLMn_R should spike
```

**Alternative method (direct voltage manipulation):**
```python
engine = brain.engines["escape_core"]
# Set V above the "will decay below threshold" point:
# V = threshold + gap * exp(-1/tau_m) ensures post-decay V >= threshold
engine.circuit.neurons["GF_L"].membrane_potential = -35.0  # well above -45
```

## 12. Risks & Unresolved Scientific Questions

### 12.1 Critical Risks

| Risk | Impact | Mitigation |
|------|--------|------------|
| **Weights calibrated too high** | High — circuit fires spuriously | Weights set to minimum single-spike threshold. No sustained input unless stimulus persists. Tests check subthreshold behavior |
| **VP->GF requires both input types** | Medium — GF won't fire if only one VPN type activated | This matches biology (Ache 2019). Nociception provides both pathways. Documented |
| **Population collapse loses synchrony** | Medium — single neuron can't replicate population dynamics | Population synchrony approximated by weight. Future phases can add population |
| **Voltage-based model misrepresents conductance** | Medium — electrical synapse dynamics differ | Calibrated to reproduce DIRECTLY_MEASURED latencies. Documented as APPROXIMATION |

### 12.2 Unresolved Scientific Questions

1. **Per-synapse quantal amplitude** — Literature gives synapse counts (2,290 LC4->GF) but not per-synapse weight. Weights are calibrated from latency targets. *(APPROXIMATION — needs paired-recording qPC analysis)*
2. **Exact looming->VPN current amplitude** — No direct measurement. *(APPROXIMATION — needs in vivo patch-clamp of LC4/LPLC2 during looming)*
3. **Contralateral chemical GF->TTMn strength** — Research report says GF->TTMn has both electrical and chemical, but doesn't specify ipsi/contra split. *(APPROXIMATION — assumed ipsi only)*
4. **GF in vivo resting potential variance** — Reported -65 mV but varies with preparation. *(DIRECTLY_MEASURED — using -65 as baseline)*
5. **ShakB gap junction conduction velocity** — 135 uS from model (INFERRED). In vivo measurement would refine weight calibration. *(INFERRED — needs dual whole-cell recording)*
6. **Nociceptor->VPN pathway anatomy** — No EM evidence for how nociceptors connect to LC4/LPLC2. *(APPROXIMATION — nociception->VPN is a functional assumption)*
