**Sodium reversal potential (E_Na)**: 65 mV — applicable to all excitable neurons

**Potassium reversal potential (E_K)**: -74 mV — applicable to all excitable neurons

**Maximal conductances** (from PMC6469880 Table 1):

- ḡK = 10 mS/cm²
- ḡleak = 0.03 mS/cm²

**Note on our current JSON parameters vs. Augustin model:**
- Our JSON has V_rest = -65 mV for GF (matches E_leak = -85 mV + resting properties from HH model)
- Our JSON has V_rest = -70 mV for TTMn, PSI, DLMn (does NOT match E_leak = -85 mV)
- Our JSON has V_threshold = -45 mV for GF, -50 mV for LC4/LPLC2, -55 mV for TTMn/PSI/DLMn

**Critical discrepancy**: Our JSON V_rest values (-65 to -70 mV) differ from the published E_leak (-85 mV). In a conductance-based HH model, V_rest emerges from the balance of leak + ionic conductances at steady state. The Augustin model's GF neuron has V_rest ≈ -65 mV (from their Figure 2B baseline), and their motoneurons settle near -70 mV. These values are **consistent with our JSON**, meaning our V_rest values are **compatible** with the published model's operating range, even though E_leak = -85 mV.

This means: for a conductance-based model, we would use E_leak = -85 mV and tune the leak conductance density so that steady-state V_rest ≈ -65 to -70 mV, matching our existing JSON.

- LC4/LPLC2: No published Na/K conductance densities or channel kinetics
- PSI: No published intrinsic conductance parameters
- DLMn: Günay et al. 2015 motoneuron parameters may apply (same cell class)

### What we should NOT assume for neurons without sources:
- LC4/LPLC2 intrinsic properties must come from the LIF approximation or require additional literature
- We cannot assign HH conductances to LC4/LPLC2 without published sources

## 4. Conductance-Based Dynamics Interface Design

### 4.1 Core Model Requirements

The `ConductanceDynamicsModel` must support:

1. **Membrane voltage (V)**: Primary state variable (mV)
2. **Leak current**: `I_leak = g_leak * (V - E_leak)` — baseline passive conductance
3. **Voltage-gated Na current**: `I_Na = g_Na(t) * m³ * h * (V - E_Na)` — HH-style spike generation
4. **Voltage-gated K current**: `I_K = g_K(t) * n⁴ * (V - E_K)` — repolarization
5. **Persistent Na current** (optional): `I_Nap = g_Nap * (V - E_Na)` — contributes to subthreshold oscillations
6. **Synaptic conductance**: `I_syn = g_syn(t) * (V - E_syn)` — chemical synapse
7. **Synaptic reversal potential (E_syn)**: 0 mV for ACh (excitatory), source-dependent
8. **Conductance decay (τ_decay)**: 1 ms for chemical synapses (from PMC6469880 Table 1)
9. **Conductance rise (τ_rise)**: 0.1 ms for chemical synapses (from PMC6469880 Table 1)
10. **Electrical/gap-junction current**: `I_elec = g_gap * (V_pre - V_post)` — bidirectional
11. **Sensory current injection**: External current added to membrane equation
12. **Threshold/spike generation**: Voltage-crossing of threshold triggers spike state
13. **Reset/refractory**: Post-spike reset to V_reset, refractory period blocks Na channels

### 4.3 Interface vs. Existing DynamicsModel Protocol

The current Protocol has:
- `inject_sensory_current(neuron, current)` — keep as-is
- `receive_synaptic_spike(neuron, weight, sign)` — needs extension for chemical vs. electrical
- `integrate(neuron, input_current)` — extend to handle conductance dynamics
- `reset(neuron)` — extend to reset gating variables

**Design decision**: The conductance model needs a separate method for electrical current accumulation, since gap-junction current depends on both pre- and post-synaptic voltages. This requires either:
- (A) Extending the Protocol with `receive_electrical_current(neuron, v_pre_minus_v_post, g_gap)`, or
- (B) Precomputing electrical currents in the engine before integration

Option (B) is preferred: the engine computes `I_elec` for each neuron from all connected electrical synapses at each tick, then passes it as part of the integration step. This keeps the Protocol stable.

**Revised Protocol extension for Phase 2:**
```

    """Accumulate gap-junction current from electrical synapses."""
```

### 4.4 Neuron State Extension

ConductanceModel neurons would need additional state:
- `g_na`, `g_k`, `g_nap`, `g_leak` (conductance densities, mS/cm²)
- `m`, `h`, `n` (gating variables, 0–1)
- `g_syn` (instantaneous synaptic conductance, µS or dimensionless)
- `E_leak`, `E_na`, `E_k`, `E_syn` (reversal potentials, mV)
- `tau_syn_decay`, `tau_syn_rise` (synaptic time constants, ms)

These would be stored in an optional `conductance_params` dict on the Neuron, populated only when the conductance model is selected.

### Critical constraint:
The existing `weight_mV` values are calibrated for the LIF model (voltage-step approximation). They cannot be directly used as conductance peak values. The conductance model needs to derive `g_peak` from the Augustin et al. published value of 80 µS.

However, 80 µS is a model parameter from the full multi-compartment NEURON model with specific cell geometry. In a point-neuron model without compartmental areas, the scaling is ambiguous.

**Recommended approach**: Use `gap_junction_conductance_us` (already in JSON) for electrical synapses. For chemical synapses, the conductance model should use a new optional field `peak_conductance_us` with a default derived from the literature (80 µS for young, per PMC6469880). If not present in JSON, fall back to a computed estimate from `weight_mV` and neuron parameters.

### Mixed synapse handling:
GF→TTMn and GF→PSI are **mixed** (electrical + chemical). In our JSON, these are represented as **two separate Synapse objects** (one `type: "electrical"`, one `type: "chemical"`). This is correct for the conductance model — both components are activated simultaneously when the presynaptic neuron spikes.

## 6. Conductance Model vs. lif_voltage Comparison

### What becomes more biologically realistic:

| Aspect | lif_voltage (current) | Conductance model (proposed) |
|--------|---------------------|------------------------------|
| Action potential shape | Hard threshold → instant reset | Full depolarization, repolarization, afterhyperpolarization |
| Ion channel kinetics | Absent (LIF approximation) | Na/K gating dynamics (m³h, n⁴) |
| Synaptic transmission | Instant voltage step | Exponential conductance change with rise/decay τ |
| Gap-junction current | Voltage step (weight_mV) | I = g_gap × (V_pre - V_post), continuously computed |
| Reversal potentials | Not modeled (single V_rest) | E_leak, E_Na, E_K, E_syn all explicit |
| Temperature sensitivity | Not modeled | Implicit via τ adjustments |
| Shunting inhibition | Not possible (sign-based) | Natural via E_syn relative to V_rest |

### Existing 3.0B.2 validation results that should remain invariant:

1. **GF→TTMn latency = 1 tick** — The conductance model should preserve monosynaptic electrical transmission speed. With dt=1ms and gap junction conductance of 135 µS, the charging should still produce spike within 1 tick.

2. **GF→PSI→DLMn = ticks 0, 1, 3** — The delay structure (GF spikes @ 0, PSI @ 1 via electrical, DLMn @ 3 via chemical synapse with delay=2) should be preserved if chemical synapse conductance and delay are properly set.

3. **Lateralization (left/right/front)** — Circuit topology unchanged; lateralization behavior should be identical.

4. **Temporal summation** — With exponential synaptic conductance decay (τ=1ms), simultaneous vs. staggered inputs should show the same summation behavior pattern.

5. **Synapse ablation results** — Disabling gap junction or chemical components should produce the same qualitative deficits.

6. **Threshold behavior** — The sensory injection current needed to trigger escape should remain approximately the same if the conductance model is calibrated to match the LIF threshold behavior.

### Results that might legitimately change:

1. **Exact threshold value** — With HH dynamics, the input current threshold for spike generation depends on the full conductance balance, not just a voltage threshold. Values may differ from 3.0B's approximation.

2. **Refractory period duration** — In the LIF model, refractory is an integer tick count. In conductance model, it emerges from Na channel inactivation kinetics. The 3.0B.2 values (GF: 5 ticks, TTMn/PSI/DLMn: 2 ticks) are approximations; the conductance model may produce different effective refractory periods.

3. **Signal magnitudes** — The `bio_` prefixed signal values (escape_signal, flight_signal, threat_signal) may scale differently under conductance dynamics since synaptic currents are now conductance-based rather than voltage-stepped.

4. **Weak stimulus edge cases** — The threshold window-dependency artifact discovered in Phase 1 (~0.287 at 50 ticks vs ~0.310 at 35 ticks) may shift because the integration dynamics differ fundamentally.

### What must remain default/off for compatibility:

- `lif_voltage` must remain the default model (`dynamics_model="lif_voltage"` in NeuralEngine)
- `conductance` model must be opt-in (`dynamics_model="conductance_v0"`)
- No JSON circuit/neuron/synapse changes that affect existing LIF behavior
- All 251 existing tests must continue to pass with default configuration

## 9. Decision Points for Implementation

1. **Point-neuron vs. multi-compartment**: Use point-neuron (no cable equation) since our existing architecture is single-compartment. This is a significant deviation from the Augustin model (multi-compartment), but necessary for compatibility with our 1-tick = 1ms discrete simulation.

2. **Gating variable initialization**: Initialize m, h, n at steady-state for V_rest. Requires source for steady-state values — can derive from HH rate equations (standard), but should note this is an approximation.

3. **Time step**: Keep dt = 1.0 ms. The Augustin model uses sub-millisecond resolution (NEURON default). At 1ms resolution, fast Na channel kinetics (τ ~ 0.1ms) will be poorly resolved. This is a known limitation to document.

4. **Conductance area scaling**: Point-neuron model doesn't need area, but the published conductances are density (mS/cm²). Must assume a reference membrane area or use absolute conductances. The gap junction values are already absolute (µS), but chemical synapse peak conductance (80 µS) is also absolute. This simplifies the model — use µS directly.

5. **Threshold detection**: In HH model, spike threshold emerges from Na channel dynamics. No explicit V_threshold needed. This changes how we report "threshold" in validation — may need to define spike as peak V > 0 mV or dV/dt > threshold.

6. **Sensory current conversion**: Current sensory input is in mV-equivalent (LIF units). For conductance model, need to convert to current (nA or µA). Requires assumed membrane capacitance and input resistance (both missing — see "Parameters we must NOT invent").

## 11. Implementation Summary

### 11.1 DynamicsModel Architecture
The `DynamicsModel` Protocol (committed at Phase 1, d8935c4) abstracts neural dynamics computation behind a minimal interface. `NeuralEngine` delegates to a pluggable model selected at construction time. `lif_voltage` remains the default and reproduces 3.0B behavior exactly.

### 11.2 ConductanceDynamicsModel / conductance_v0
An opt-in model implementing reduced conductance-based dynamics:
- **Electrical current**: `I_elec = g_gap * (V_pre - V_post)` computed per electrical synapse in `_compute_electrical_currents()`
- **Chemical conductance**: `receive_synaptic_spike()` increments `g_syn` by the model's `g_syn_peak_us` parameter (80 µS, from PMC6469880 Table 1, labeled "estimated")
- **Conductance decay**: `g_syn *= exp(-dt / tau_syn_decay_ms)` with `tau_syn_decay_ms = 1.0`
- **Membrane current balance**: `compute_leak_current`, `compute_synaptic_current`, `compute_electrical_current`, `compute_ionic_current` — `I_ion` returns 0.0 (no HH gating)
- **Voltage integration**: Passive Forward Euler: `dV/dt = (I_applied - I_leak - I_syn - I_ion + I_elec) / C_m`
- **Spike-event adapter**: Upward threshold crossing detection (V_before < threshold AND V_after >= threshold) with reset and refractory inheritance

### 11.3 ConductanceNeuronState
Per-neuron optional state on `Neuron.conductance_state` (defaults to `None`). When `None`, `_ensure_conductance_state()` raises `RuntimeError`. `attach_conductance_state()` is an explicit opt-in helper. LC4, LPLC2, and PSI neurons are expected to remain on `lif_voltage` — no conductance state is auto-assigned.

### 11.4 Explicit Membrane-Area Requirement
`integrate()` raises `NotImplementedError` when `ConductanceParams.membrane_area_cm2` is `None`. This resolves the unit incompatibility between density conductances (`g_leak` in mS/cm²) and absolute conductances (`g_syn`, `g_gap` in µS). No biological membrane area was inventoried from literature.

### 11.5 End-to-End NeuralEngine Validation
The conductance model integrates with `NeuralEngine.step()`:
1. Decay conductances
2. Inject sensory current (raises `NotImplementedError` — sensory conversion not implemented)
3. Process delayed chemical spikes
4. Compute electrical currents
5. Integrate all neurons
6. Clear electrical current accumulators
7. Schedule propagation (skips electrical synapses in conductance mode)
8. Read outputs

### 11.6 Invariant Validation Performed
The following invariants were verified where the architecture permits:
- `lif_voltage` remains the default and reproduces 3.0B.2 numerically
- `lif_voltage` is unaffected by conductance model construction or state
- `I_elec_accumulator` is cleared after each timestep (no stale current leakage)
- Chemical conductance accumulates and decays per exponential law
- Leak current pulls voltage toward `E_leak` (-85 mV)

## 12. Explicit Limitations

1. **No Hodgkin-Huxley gating**: `I_ion` is always 0.0. Voltage-gated Na/K gating variables (m, h, n) are NOT implemented.
2. **No active Na/K kinetics**: No transient sodium, persistent sodium, or potassium channel equations.
3. **Single-compartment**: No multi-compartment morphology, no cable equation, no dendritic/soma separation.
4. **1 ms timestep**: The published GFS model and experimental GFS literature operate at sub-millisecond resolution. Fast Na activation τ ~ 0.1 ms cannot be resolved at dt = 1 ms.
5. **No sensory-to-current conversion**: `inject_sensory_current()` raises `NotImplementedError`. Sensory input remains in the LIF voltage abstraction (mV-equivalent). No input resistance or membrane area measurements exist for any neuron in the cited literature.
6. **No per-neuron dynamics selection**: `NeuralEngine` uses a single `dynamics_model` for all neurons in a circuit. Mixed-model execution (some neurons on `lif_voltage`, others on `conductance_v0`) is architecturally blocked.
7. **Full escape-circuit conductance validation is blocked**: Because the escape circuit's input neurons (LC4, LPLC2) and PSI are required to remain on `lif_voltage` (no source-supported HH parameters), and the engine uses a single dynamics model for all neurons, the conductance model cannot be validated against the full escape circuit without relaxing constraint #6.
8. **Not a reproduction of the published GFS model**: The Augustin et al. 2019 model (PMC6469880) is a 4-cell, multi-compartment NEURON implementation with active ion channels. This implementation is a reduced single-compartment approximation using literature-informed parameters, not a faithful reproduction.
9. **Software/model validation only**: No validation claims are made against biological latency measurements or behavioral phenotypes.

## 15. Future Work

### Research gaps that must be resolved before biological claims:
- **Neuronal input resistance**: No source provides input resistance for GF, TTMn, PSI, DLMn, LC4, or LPLC2. Required for sensory-current-to-voltage conversion in a conductance model.
- **Neuron-specific Na/K conductance densities**: PMC6469880 provides motoneuron parameters via Günay et al. 2015, but no published source provides intrinsic conductance parameters for LC4, LPLC2, or PSI.
- **Membrane area per neuron**: No anatomical source provides soma plus dendritic membrane area for any neuron in this circuit.
- **Temperature correction factors (Q10)**: All electrophysiology measurements are at unspecified or room temperature. No Q10 values provided in cited literature.

### Architectural gaps:
- **Per-neuron dynamics selection**: Required to run a mixed-model escape circuit where LC4/LPLC2/PSI remain on `lif_voltage` while GF/TTMn/DLMn use `conductance_v0`. Currently blocked by single-model-per-engine design.
- **Sub-millisecond simulation**: Required to faithfully resolve HH channel kinetics. The 1 ms timestep makes active conductance dynamics an explicit approximation.

### Notes on lost test history:
During Phase 2 development, an uncommitted working-tree test suite of approximately 345 tests was reported (including ~82 tests added for Steps 2–9 validation). Those tests existed only in the working tree and were accidentally lost before checkpointing. They were NOT recreated. The current committed suite contains 263 tests.
