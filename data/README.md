# MaleCNS data provenance and use

## Dataset identity and source

Repository records identify the source as the **MaleCNS v1.0 connectome** (`male-cns:v1.0`), a male adult *Drosophila melanogaster* connectome.

- Public portal: <https://male-cns.janelia.org/>
- Dataset root: `gs://flyem-male-cns/v1.0/`
- PSI→MN5 synapse annotation layer: `gs://flyem-male-cns/v1.0/male-cns-v1.0-synapses-precomputed/`
- Recorded contact table: `syn-partners-male-cns-v1.0-minconf-0.5.feather`, Feather format, approximately 6.5 GB in the repository inventory.
- Recorded pairing: PSI 802401→MN5 801970 and PSI 903327→MN5 801295; contacts are filtered at minimum confidence 0.5.
- Dataset citation recorded in the source registry: Berg et al. (2026), “Sexual dimorphism in the complete Drosophila male central nervous system connectome,” *Cell* 189(18):5504–5526.e15, DOI `10.1016/j.cell.2026.08.015`, dataset v1.0.

## Expected files and retrieval

The code expects the partner Feather file in the operating system's temporary directory under the exact filename above. `research/scripts/retrieve_malecns_compartment_post.py` reads that already-staged local file and obtains matching per-synapse annotation records from the public precomputed layer over HTTP range requests. It is not a command for downloading the large Feather file. The repository records no complete command for staging that raw file, and this README does not supply one.

The annotation-processing script documents:

```text
python research/scripts/retrieve_malecns_compartment_post.py
```

It writes the derived `research/artifacts/malecns_compartment_post_psi_mn5.csv` and `research/artifacts/malecns_compartment_post_summary.json`. The per-contact SWC concordance is generated by:

```text
python research/scripts/analyze_mn5_compartment_post_swc_type.py
```

That script expects `em_801970.swc` and `em_801295.swc` in the system temporary directory and uses the processed contact annotation artifact. It writes `research/mn5_compartment_post_swc_type_concordance.csv` and its Markdown companion. `research/scripts/analyze_mn5_two_gate_constraint_model.py` consumes the concordance table and cached SWCs to produce `research/mn5_psi_mn5_final_constraint_model_sensitivity.csv`.
